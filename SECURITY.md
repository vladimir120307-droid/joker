# Безопасность

Об уязвимостях сообщайте закрыто: откройте вкладку **Security** репозитория и нажмите **Report a vulnerability** ([прямая ссылка](https://github.com/vladimir120307-droid/joker/security/advisories/new)). Пожалуйста, не публикуйте подробности в issue или обсуждениях, пока проблема не исправлена.

Опишите, в какой части проекта проблема (расширение, браузер для ПК, приложение для Android), как её повторить и чем она опасна.

Исправления выходят для последней версии из раздела Releases.
