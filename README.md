# JOKER

Сайт видит, что окно открыто **на весь экран**, и **не узнаёт, что вы ушли** в другое окно, вкладку или приложение.
Один и тот же код работает тремя способами: расширением для браузера, отдельным браузером для ПК и приложением для Android.

| Режим | Что видит сайт |
|---|---|
| **Полный экран** («Экран») | `document.fullscreenElement`, `requestFullscreen()` (успешно «срабатывает», окно при этом не меняется), `innerWidth/innerHeight` = размер экрана, `(display-mode: fullscreen)`, событие `fullscreenchange`. |
| **Скрыть переключение** («Скрыть») | `document.hidden = false`, `visibilityState = "visible"`, `document.hasFocus() = true`; события `visibilitychange`, `blur`, `focus`, `mouseleave` до страницы не доходят (blur/focus у полей ввода не трогаются). |

Режимы включаются отдельно и «при необходимости». Подменённые функции маскируются под нативные (`toString()` отдаёт `[native code]`), подмена работает и внутри вложенных iframe, в том числе чужих доменов.

## Что выбрать

| Вариант | Где работает | Папка |
|---|---|---|
| Расширение | Chrome, Edge, Brave, Opera, Яндекс.Браузер; Firefox и Firefox для Android | [`extension/`](extension) |
| Приложение для Android | Android 8.0 и новее | [`android/`](android) |
| Браузер для ПК | Windows, macOS, Linux (Electron / Chromium) | [`desktop/`](desktop) |

iPhone не поддерживается: для этого нужны Mac, Xcode и аккаунт разработчика Apple.

## Расширение (Chrome, Edge, Brave, Opera, Яндекс.Браузер)

1. Откройте `chrome://extensions` (или `edge://extensions`) и включите **«Режим разработчика»**.
2. **«Загрузить распакованное расширение»** → папка `extension/`.
3. Нажмите на значок JOKER и для каждого режима выберите **Выкл / Этот сайт / Все сайты**.
   Применяется сразу, без перезагрузки. «Этот сайт» запоминается и включается с первого скрипта страницы.
4. Горячие клавиши (для текущей вкладки, без запоминания): `Alt+Shift+F` — полный экран, `Alt+Shift+H` — скрыть переключение.

Ограничение: «Этот сайт» покрывает сам домен и его поддомены. Iframe с *другого* домена защищается при «Все сайты» или если режим включён вручную в уже открытой вкладке (popup применяет его во всех фреймах вкладки).

### Firefox и Firefox для Android

`node tools/build-extension.js firefox` создаёт `dist/JOKER-extension-firefox.zip`. Чтобы поставить его на обычный Firefox, архив нужно подписать в Mozilla (бесплатно: addons.mozilla.org → «Submit a New Add-on» → «On your own»); временно можно загрузить через `about:debugging`. В настройках расширения включите «Доступ к данным на всех сайтах». Сборка для Firefox **не проверялась** на реальном Firefox.

## Приложение для Android

Нативный браузер на системном WebView (Chromium): адресная строка с поиском Google, вкладки, поиск по странице, «версия для ПК», загрузки, выбор файлов, диалоги `alert/confirm/prompt`, запросы камеры, микрофона и геопозиции, видео на весь экран, тёмная тема. Может быть браузером по умолчанию (открывает ссылки из других приложений).

**Установка.** Скачайте `JOKER.apk` (около 100 КБ) из раздела Releases или соберите сами (см. ниже), перенесите на телефон, откройте файл и разрешите установку из этого источника.

**Управление.** Внизу: назад, вперёд, **Экран**, **Скрыть**, вкладки, меню. Режимы включаются тапом, включённый подсвечен; они работают отдельно на каждой вкладке, а вкладка, открытая со страницы (`window.open`, ссылка в новом окне), наследует режимы родителя. Долгое нажатие на кнопку режима открывает справку.

**Приватность.** Cookie, кэш, localStorage и история лежат в отдельном профиле WebView, который создаётся на каждый запуск. При выходе и при «Завершить сеанс…» данные профиля стираются сразу (на диске не остаётся ни значений, ни адресов посещённых сайтов, это проверяется тестом), а его пустой каталог убирается при следующем запуске: WebView не умеет удалять профиль в том же процессе, где он использовался. Если приложение убили, остаток тоже удаляется при следующем запуске. Сторонние cookie блокируются (переключается в меню). Заголовки `DNT` и `Sec-GPC` на Android **не** отправляются (WebView не позволяет добавлять заголовки ко всем запросам).

**Особенности.** На Android WebView при уходе приложения в фон страница получает только `visibilitychange` (и `document.hidden = true`), события `blur` не приходят вовсе. Именно это режим «Скрыть» и закрывает. Загрузки `blob:` и `data:` ссылок не поддерживаются. Открытие `http`-сайтов разрешено (в адресной строке горит предупреждение).

### Сборка Android

Нужны JDK 17+ (подойдёт JBR из Android Studio) и Android SDK с платформой 36.

```
cd android
./gradlew :app:assembleRelease    # android/app/build/outputs/apk/release/JOKER-release.apk
./gradlew :app:assembleDebug      # отладочная сборка (включает отладку WebView, нужна для проверки)
```

Без своего ключа APK подписывается отладочным ключом: он сразу ставится, но обновить такой APK можно только сборкой с того же компьютера. Чтобы обновления ставились поверх, создайте свой ключ и передайте его переменными окружения:

```
keytool -genkeypair -v -keystore joker.keystore -alias joker -keyalg RSA -keysize 2048 -validity 10000
JOKER_KEYSTORE=/путь/joker.keystore JOKER_KEYSTORE_PASSWORD=... JOKER_KEY_ALIAS=joker JOKER_KEY_PASSWORD=... ./gradlew :app:assembleRelease
```

Файл ключа **не коммитьте** (он в `.gitignore`) и не теряйте: без него обновления не встанут поверх старой версии.

## Браузер для ПК

```
cd desktop
npm install
npm start          # или start.bat на Windows
npm run selftest   # автотест в настоящем Chromium
```

Вкладки в заголовке окна, омнибокс, поиск по странице, контекстное меню и горячие клавиши как в Chrome (`Ctrl+T/W/L/R/F`, `Ctrl+Tab`, `Ctrl+1..9`, `Ctrl+Shift+T`, `F11`, `F12`, `Alt+←/→`, масштаб), в том числе в русской раскладке. Режимы переключаются кнопками на панели или `Ctrl+Shift+F` / `Ctrl+Shift+H`. Сессия только в памяти, `DNT` и `Sec-GPC`, без утечки локального IP через WebRTC, камера/микрофон/геопозиция только по запросу. Поисковик меняется в `SEARCH_URL` в `main.js`.

## Как это устроено

Вся подмена живёт в одном файле, [`extension/core.js`](extension/core.js). Он выполняется в странице (в основном мире и во всех фреймах) до скриптов сайта и читает флаги из общего состояния, а «клей» для каждой платформы лишь выставляет эти флаги:

* **расширение**: `flag-*.js` регистрируются для выбранных сайтов, а `popup` переключает режимы вкладки на лету;
* **браузер для ПК**: [`desktop/preload-page.js`](desktop/preload-page.js) генерируется из `core.js` командой `node tools/sync-core.js` (проверка актуальности: `--check`);
* **Android**: Gradle копирует `core.js` в assets, а `document-start`-скрипт WebView выполняет его в каждом фрейме; [`bridge.js`](android/app/src/main/assets/js/bridge.js) доносит живое переключение до вложенных iframe.

```
extension/    расширение (MV3): здесь только файлы, которые грузятся в браузер
tests/        тест расширения в настоящем Chromium (tests/extension)
desktop/      браузер для ПК на Electron
android/      приложение для Android и проверка на устройстве (android/e2e)
tools/        иконки, сборка расширения для Chrome и Firefox, синхронизация core.js
.github/      сборка в CI: расширение, APK, релиз по тегу v*
```

## Что проверено

Всё ниже запускалось в настоящем Chromium/WebView, а не на заглушках:

* **Расширение**: `tests/extension` (Playwright + Chromium; запуск: `cd tests/extension && npm install && npm run install-browser && npm test`): подмена, живое включение, включение с первого скрипта после перезагрузки, сохранение настроек после перезапуска браузера, popup.
* **Браузер для ПК**: `npm run selftest`: реальный уход из окна (второе окно, `hide`, `minimize`), iframe на другом origin, маскировка, приватная сессия, заголовки.
* **Android**: `android/e2e/run.mjs` на эмуляторе Android 15 (WebView 158): настоящий уход в фон кнопкой Home, тапы по кнопкам режимов, iframe другого сайта, перезагрузка, всплывающие окна, видео на весь экран, ввод адреса и клавиатура, страница ошибки и «назад» с неё, диалоги JS, запрос микрофона, версия для ПК, поиск, загрузка файла, приватность по следам на диске, выход и повторный запуск, поворот экрана, смена темы. `android/e2e/release-smoke.mjs` проверяет то же главное в релизной сборке (R8, без отладочного порта).

Не проверялось: Firefox и Firefox для Android, физический телефон (только эмулятор), macOS и Linux для браузера на ПК.

## Релизы

`.github/workflows/build.yml` на каждый push собирает расширение и APK; по тегу `v*` (например `git tag v1.0.0 && git push --tags`) публикует релиз с `JOKER.apk` и архивами расширения. Чтобы APK из CI подписывался вашим ключом, добавьте секреты репозитория `JOKER_KEYSTORE_BASE64` (`base64 -w0 joker.keystore`), `JOKER_KEYSTORE_PASSWORD`, `JOKER_KEY_ALIAS`, `JOKER_KEY_PASSWORD`.

## Честно о пределах

Эти функции скрывают события **на стороне страницы**. Они не влияют на то, что сайт может узнать иными способами: через камеру или запись экрана, отдельное программное обеспечение на устройстве или анализ на стороне сервера. Подмена полного экрана меняет только то, что сообщается странице: JavaScript сайта, который строит вёрстку по `innerWidth/innerHeight`, увидит размеры экрана, а не реального окна.
